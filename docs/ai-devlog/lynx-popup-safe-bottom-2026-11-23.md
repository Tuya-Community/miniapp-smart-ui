# Lynx Popup 底部留白与受控显示

> 需求来源：本次对话，爬宠喷淋时长与循环间隔弹窗对齐 WebView。
> 负责人：田坤（tiankun）；AI 工具：Codex；日期：2026-11-23。
> 状态：本地源码修正，安卓真机通过，iOS 待重新连接；未发布、未提交或推送。

## 技术方案

仅在隔离的 Lynx 构建中注册 Popup 适配器，按可绘制窗口与 safeArea.bottom 计算底部安全区，再加 16px 基础间距并取显式最小值；传给原生 WXS 为具体像素，避免原有嵌套 max/env 不生效。保留 customStyle 最终覆盖、原动画及蒙层铺满窗口。实例 resize 监听成对清理。
