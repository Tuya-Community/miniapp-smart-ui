# Lynx Picker 首绘和拖动更新优化

- 日期：2026-11-23；负责人：田坤；工具：Codex；来源：门禁临时通行时分首次空白、双端滚动卡顿。
- 授权：沿用用户允许修改本地 Smart UI 源码并验证的授权；工作分支 codex/lynx-smart-ui。此前 Popup 安全区补丁保留，不编辑依赖安装目录。

## 变更

- Picker 仍有明确尺寸 viewport 和原生绝对绘制坐标；取消 mounted → getRect → opacity 的额外首次显示等待。仅此修改不能完全消除业务按需创建时的空白，主项目另将开始/结束滚轮分别按真实面板值提前准备，并在隐藏时复位。
- PickerColumn 每次移动把 animationIndex 与位移合入一次 setData；当前虚拟窗口未变时不重传行数组、不重复解析主题样式。窗口索引、当前选中、选项、字号/字重来源等变化后更新，主题切换显式清缓存。
- 可见行透明度移到 WXS 纯计算，公式与原模型一致，不发起定时器或 DOM 操作；保留虚拟行 key、选中/禁用状态、取消恢复、多指结束校验和卸载清理。
- 包含 build/lynx.cjs、lynx-runtime/adapters.ts、picker-column/index.wxml / index.wxs、交互/模型/产物测试以及生成清单。packages、dist/lib WebView 源与基准产物不改。

## 验证

- 旧实现的性能断言失败：120 次小移动有 240 次桥更新、120 次整组行重发。候选对应 120 次更新、0 次行重发。此为确定性更新预算，不换算成真机 FPS。
- SDK 63 项测试通过；覆盖循环负/正索引与跨窗位置、主题/显式文字样式、空列、禁用项、取消和卸载、WXS 连续透明度、首绘不再依赖测量。
- 70 个隔离组件校验通过；SDK 适配 TS 的 ESLint 通过。原 WebView 源与产物校验一致。
- 主项目联编标记 36705c08ee0cef00，安卓与 iOS 已推送。安卓首次打开有当前值，取消重开恢复；iOS 回归结果以主项目 docs/ai-devlog/lynx-temp-access-time-performance-2026-11-23.md 为准。
- Android 系统录屏不可用，截图仅用于采样帧与数值核验，不声明绝对帧率或完全等同 WebView 的流畅度。暗色/大屏本轮无额外真机验收。
- 未提交、未推送 Git，也未发布 npm；主项目仍固定线上版本，当前优化通过显式本地 SDK 调试入口联编。
